## 保持的后端契约

沿用 Spring Boot 4.1.1、Java 17 和 sg.edu.nus.iss.shoppingcart。保留 A 的 app_users、已有 ID 和 BCrypt 密码；补充 email 与 CUSTOMER/ADMIN 角色。身份仍为 Session 中的 Long loginUserId，不保存密码哈希或整个用户实体。

认证通过后建立新 Session；退出和切换账号销毁旧会话，不继承旧购物车、结账状态或成交回执。注册和个人资料在服务端校验，表单不能指定用户 ID 或提升角色。权限拦截先验证身份，再判断数据库中的管理员角色；普通用户直接访问或提交后台请求仍被拒绝。

AuthService 承担认证、注册和资料业务；Controller 负责请求和响应，Repository 承担持久化。C/D 的 Java 文件逐字节保留，其他模块成果不计为 B 独立开发。
