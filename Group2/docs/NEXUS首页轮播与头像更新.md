# NEXUS Digital：首页轮播、每日促销与头像

日期：2026-10-10。

## 头像与促销数据

本地选择的图片最多 8 MB。原图在浏览器中裁剪，仅上传裁剪后的头像。服务器验证图片内容、尺寸和登录账号，重新编码为 512 × 512 JPEG 后保存到独立的 `account_avatars` 表；不接收客户端指定的其他用户 ID，写入操作验证会话表单令牌。上传后的头像在账户页面以圆形显示，数据库保留规范化的方形图片。

促销页日期使用新加坡时区，价格和折扣读取当前商品数据；管理员调整折扣后，重新打开或返回促销标签页即可获取更新。没有可用优惠时显示空状态，不指定过期或不可购买的最高优惠。

## 使用

已启动本轮独立预览：<http://127.0.0.1:18089/products>。促销页：<http://127.0.0.1:18089/deals>。

普通演示账号：`alice / demo123`；管理员：`admin / admin123`。登录后进入“账户”上传头像；管理员从导航的“管理后台”调整商品折扣。

在含 `pom.xml` 的项目目录运行：

```powershell
java -jar runtime/nexus-shopping-cart.jar --spring.profiles.active=b-demo --server.port=18089
```

已有预览运行时无需重复启动。H2 演示数据在重启后重置；正式 MySQL 使用数据库保存头像。本轮没有连接既有 MySQL 数据库。
