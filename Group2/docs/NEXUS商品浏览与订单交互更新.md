# NEXUS Digital：商品浏览与订单交互更新

日期：2026-10-10。本轮完成商品浏览与订单页面的四项调整。

| 项目 | 更新后的行为 |
| --- | --- |
| 商品卡片 | View details 固定在卡片内容底部。同一行中促销与非促销商品的按钮对齐，手机双列布局同样适用。 |
| 指定页跳转 | 支持点击页码，或输入页码后点击 Go／跳转。保留分类、搜索、排序和每页数量，切换后定位到商品区。无效页码按所选语言提示；较多页码使用省略号。 |
| 评价入口 | 确认收货后显示小尺寸线条铅笔按钮；提交后显示勾选图标及 Reviewed／已评价。手机端按商品分组展示，评价入口完整可见。 |
| 订单商品 | 商品明细标题改为 Order products／订单商品，评价列为 Review／商品评价。订单详情和结账页中的每个商品名称均可打开对应详情。提交评价后，详情中的评论、评价数量及平均星数同步更新；返回先前打开的详情标签页也会刷新。 |

评价接口返回 `Cache-Control: no-store`，避免浏览器复用旧的评论或当前用户评价状态。评价权限继续由服务层校验，确认收货前不显示评价入口。

## 运行

本轮已启动预览：<http://127.0.0.1:18088/products>。

在包含 `pom.xml` 的项目目录可运行：

```powershell
java -jar runtime/nexus-shopping-cart.jar --spring.profiles.active=b-demo --server.port=18088
```

若当前预览仍在运行，无需重复启动。普通演示账号为 `alice / demo123`，管理员为 `admin / admin123`。演示环境使用内存 H2，重启会重置演示数据；本轮未连接既有 MySQL 数据库。
