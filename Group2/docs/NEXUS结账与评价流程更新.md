# NEXUS Digital：结账与评价流程更新

日期：2026-10-10。本轮覆盖最新 13 项要求，替代前一版的一步支付和订单详情内评价表单。

## 13 项变更

| 项目 | 现在的行为 |
| --- | --- |
| 注册显示密码 | 密码与确认密码输入框各有独立小眼睛，支持键盘操作和中英文标签。 |
| 登录落点 | 普通用户和管理员登录成功都进入首页，导航栏保留管理后台入口。 |
| 分类选购 | 横向紧凑分类栏，选中高亮，悬停及商品切换动画；切换分类后平滑定位商品区，并尊重减少动画设置。 |
| 评论语言 | 每条预置评论仅有英文或中文，英文约占四分之三。 |
| 评分分布 | 大多数商品在 4 星以上，少量中低分，保留满分与约 1.8 星的极端值；页面移除 Sample review 标记。 |
| 数量同步 | 总览与详情读取相同购物车数量，两个界面都可加减；归零恢复加购入口。 |
| 订单与支付 | 先提交并保存待付款订单，再进入 `/orders/{id}/payment`；支付成功后状态为已支付。待付款订单可从订单列表继续支付。 |
| 银行卡表单 | Visa / Mastercard 可选，卡号自动四位分组，有效期自动转为 MM/YY；移除演示填充、支付密码和成功/失败选择。通过输入与库存校验后默认支付成功。 |
| 收货提示 | “您确认收货后，即可为商品留下评价。” |
| 评价入口 | 确认收货后每个商品行出现评价图标；进入独立评价页，五颗灰星快速选分并填写内容；提交后回订单，显示“已评价”。 |
| 支付凭证 | 移除凭证中的模拟交易字样，订单详情可下载 PDF，包含编号、时间、交易参考号、银行卡组织及尾号、商品明细、折扣、GST 和总额。 |
| 折扣上限 | 后台、表单与实体校验统一允许 0～99% 优惠；0 表示不促销。金额最低为 S$0.01。 |
| Order total | 购物车、结账、支付、订单详情显示原价合计、优惠、折后小计、9% GST 和应付总额。 |

## 金额与订单规则

新订单把商品价格视为未含 GST 的金额。先按每件商品折扣计算实际单价，再按折后小计计算 9% GST，保留两位小数并四舍五入。例如原价 S$99.99、25% 优惠、3 件：原价合计 299.97，折后单价 74.99，折后小计 224.97，优惠 75.00，GST 20.25，应付 245.22。

下单时保存价格、折扣、税额、商品名称和地址快照。后续管理员改价或用户改地址不会修改该订单。旧订单保持原有成交金额，不补算税。提交订单后清空对应购物车；库存到支付时再次锁定、核对及扣减。重复提交和重复支付不会重复生成订单或扣库存，多个用户同时支付最后一件商品也不会超卖。

待付款订单不能确认收货、评价或下载支付凭证。支付完成后模拟物流立即推进到签收，买家再确认收货才能评价。查看订单、支付、确认、评价和下载均校验当前账号归属；网页 POST 使用会话表单令牌。

支付仍为本地网关演示，不发起真实扣款。完整卡号、安全码不入库、不进入日志或下载凭证；凭证只保留卡组织和末四位。PDF 使用嵌入的 OFL 授权 Noto Sans SC 字体，支持中文和长订单自动分页。它是付款收据，不冒用缺少商家注册资料的 GST tax invoice。

税额与收据字段参考：[IRAS 折扣与 GST](https://www.iras.gov.sg/taxes/goods-services-tax-%28gst%29/charging-gst-%28output-tax%29/common-scenarios---do-i-charge-gst/gst-on-discounts-and-rebates)、[IRAS 客户开票](https://www.iras.gov.sg/taxes/goods-services-tax-%28gst%29/basics-of-gst/invoicing-price-display-and-record-keeping/invoicing-customers)。

## 运行与使用

本轮预览：<http://127.0.0.1:18087/products>。管理员 `admin / admin123`，登录后在首页导航点击管理后台。普通演示账号 `alice / demo123`。

在包含 `pom.xml` 的目录运行：

```powershell
java -jar runtime/nexus-shopping-cart.jar --spring.profiles.active=b-demo --server.port=18087
```

`Start-Demo.cmd` 会自动选择最新运行包；默认端口为 18083。演示数据库为内存 H2，重启会重置演示数据。MySQL 的连接配置没有改动，本轮未对既有 MySQL 数据库执行验证。

演示步骤：加购 → 核对收货地址与 GST → 提交订单 → 待付款页输入银行卡 → 支付 → 查看/下载凭证 → 确认收货 → 点击商品行评价 → 选星并提交。

可手动输入测试卡号 `4242 4242 4242 4242`（Visa）或 `5555 5555 5555 4444`（Mastercard），有效期使用未来月份，例如 `12/99`，安全码 `123`。页面没有快捷填充按钮。
