# NEXUS Digital：单行分类、三张横幅与公共头像

日期：2026-10-10。

## 本轮行为

- 首页分类导航在桌面上保持一行，使用简短分类名，悬停可查看完整名称。1050px 及以下使用同一行的分类选择框，保留所有类别与商品，无需横向滑动。选择分类后定位商品区。
- 删除横幅播放/暂停图标。保留悬停显示的左右箭头、每 6 秒自动循环、悬停和键盘聚焦暂停、后台标签页暂停以及减少动画偏好。
- 修正第二张 Daily deals 台灯插图的矩形背景及外框阴影。
- 保留原有两张横幅，增加第三张“今日特惠”：读取当前在售且有库存商品中的最高折扣，显示商品名称、折扣、原价、优惠价和图片，按钮直接打开对应商品详情。并列折扣沿用销量和 ID 排序。没有可用优惠时显示促销页入口。返回浏览器标签页时重新获取优惠数据。
- 首页、商品详情、每日促销、购物车、订单、账户和地址等页面，统一在用户名旁显示 28px 圆形头像。未上传时显示姓名首字。上传后账户导航立即更新，已打开的其他标签页在返回时同步更新；不同账号使用各自头像。

## 运行

本轮预览：<http://127.0.0.1:18090/products>。

演示普通账号 `alice / demo123`、`bob / demo123`；管理员 `admin / admin123`。

从含 `pom.xml` 的目录启动最新运行包：

```powershell
java -jar runtime/nexus-shopping-cart.jar --spring.profiles.active=b-demo --server.port=18090
```

已有预览运行时无需重复启动。演示使用独立 H2 内存数据库，重启会重置；本轮没有操作现有 MySQL 数据库。正式配置下头像仍通过数据库持久保存。
